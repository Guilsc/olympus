# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities through GitHub's private vulnerability
reporting feature for this repository. Do not open a public issue or pull
request containing vulnerability details, credentials, private data, or an
exploitation procedure.

Include the affected component, reproduction conditions, expected impact, and
the smallest safe proof needed to evaluate the report. You will receive an
acknowledgement after the report is reviewed.

## Supported versions

Olympus is in active development and does not yet publish supported releases.
Security review currently applies to the default branch.
