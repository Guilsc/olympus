# Contributing

Olympus is under active architectural development, and external contributions
are temporarily paused. Please do not open pull requests, issues, or review
requests yet. The public repository remains available for reading, cloning, and
personal experimentation.

Contribution guidelines and an initial public roadmap will be added when the
project reaches a stable collaboration boundary.

Security concerns should not be posted publicly. Follow the private reporting
instructions in [SECURITY.md](SECURITY.md).
