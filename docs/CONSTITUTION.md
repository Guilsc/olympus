# Constitution

1. Architectural roles are canonical; narrative identities are aliases.
2. Theme must never define system behavior.
3. Complexity must be earned by demonstrated need.
4. Every mutable side effect has one active owner.
5. Authority is explicit, bounded and least-privileged.
6. Chat is an interface, not canonical state.
7. Agent, skill, tool, memory, policy and artifact are distinct concepts.
8. Autonomous/background execution must be observable and interruptible.
